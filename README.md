# MiniDex

An iOS Pokédex app built with Swift and SwiftUI.

## Features
- Search any Pokémon by name with live sprites and type data powered by the PokéAPI
- Build a custom team of up to 6 Pokémon
- Full type matchup chart for all 18 types

## Tech Stack
Swift, SwiftUI, Xcode, URLSession, REST API (PokéAPI)
